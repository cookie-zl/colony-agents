# 装进镜像的插件清单：一行一个 npm 装配 spec，写法与 `dsh plugin add <spec>` 完全一致。
#
#   - 必须是「包名@确切版本」。不要写 `^`/`~`/`latest`：
#     镜像要能被同一条 git commit 复现，浮动版本会让线上悄悄变形。
#   - `#` 开头是注释，空行忽略，行内不支持注释。
#   - 这里装的包必须声明 `dsh.bundle`（组合包），否则只会成为普通依赖、不激活任何配置层。
#   - 每一行都等于「允许这个包的代码在服务器上以 dsh 的身份执行」，见 docs/03-社区插件.md。
#
# 装完由 dsh 自动写进 profile/package.json 的 dependencies 与 dsh.profile.bundles。
