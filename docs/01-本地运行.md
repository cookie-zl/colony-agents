# 01 · 本地运行

目标：在本机用和线上一样的镜像、一样的 profile 跑起来，作为后面所有事情的基线。

## 前置

- Docker（本机用的是 OrbStack，`docker compose` 已内置）
- 一个 DeepSeek API Key

## 起服务

```bash
cp deploy/compose/.env.example deploy/compose/.env
# 编辑 deploy/compose/.env，至少填 DEEPSEEK_API_KEY
make up
```

首次会构建镜像（约 1~3 分钟，取决于网络），之后走缓存。

看容器：

```bash
make ps
# NAME                 STATUS
# my-dsh-dsh-1         Up (healthy)
# my-dsh-edge-1        Up
```

## 第一次访问：token 换 Cookie

入口是 `http://dsh.localhost:8080/`（`*.localhost` 在 macOS / Linux 上自动解析到 127.0.0.1，不用改 hosts）。

**直接开这个地址会 401。** dsh 的访问控制是「打印出来的 URL 里带 token → 服务端换成签名 Cookie」，所以第一次必须用带 token 的链接：

```bash
make token
# http://dsh.localhost:8080/?token=xxxx
```

浏览器打开它，会回一个 303，把 token 换成 HttpOnly Cookie（有效期 30 天），之后同一浏览器直接访问根地址就行。

这一步是后面「访问控制」章节的基础：**token 就是凭据**，谁拿到谁进来，dsh 自己不做用户体系。

## 这套栈里到底跑了什么

```bash
make shell                                   # 进 dsh 容器
ps -o pid,ppid,comm -p 1                    # PID 1 是 tini，它下面才是 dsh
dsh --profile web --dump-config | grep '^# =='  # 看实际生效的配置层
```

在容器里看到的边界：

| 观察点 | 预期 |
| --- | --- |
| 进程数 | 只有 6 个左右（tini + dsh + 少量 worker），没有 docker CLI |
| `/var/run/docker.sock` | 不存在 |
| 用户 | `dsh`（uid 1000），不是 root |
| 任务产物 | 只出现在 `/workspace`，也就是宿主的 `deploy/compose/workspace/` |

agent 在容器里跑命令**不会**跳出容器：它没有宿主 PID 命名空间、没有 docker socket，`workspace-write` 模式下的可写范围就是 `/workspace`。

## 沙箱是否生效

Linux 上 dsh 用 Landlock（不是 bubblewrap）限制子进程的文件访问，**fail closed**：内核不支持就直接起不来，不会静默降级。

```bash
make logs | grep -i landlock
# 期望看到 fully enforced 字样
```

内核要求 ≥ 5.13。本机 OrbStack 的内核 7.x，没问题。

## 常见故障

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 开首页 401 | 没用带 token 的链接 | `make logs \| grep token` 取最新 URL |
| 带 token 也 401 | 容器重启过，token 变了 | 重新取 URL；旧 Cookie 已失效 |
| 页面能开但 `/api` 全 403 | 反代改写了 Host | Caddy 里必须是 `header_up Host {host}` |
| 容器一直 unhealthy | 探针连了 127.0.0.1 | dsh 绑的是容器自己的 IP，探针要连 hostname |
| `dsh plugin add` 报 ECONNREFUSED | 容器里继承了宿主的 `HTTP_PROXY=127.0.0.1:xxxx` | 别在 `.env` 里传宿主代理；要借宿主代理用 `host.docker.internal` |
| 构建时 `npm install` 超时 | 走不了公网 registry | 改 `.env` 的 `NPM_REGISTRY` 为内网源 |
| 构建卡在 `apt-get` 十几分钟 | 官方 `deb.debian.org` 在部分网络下只有 ~1MB/min | 改 `.env` 的 `APT_MIRROR`（默认已设 `mirrors.aliyun.com`） |
| 拉基础镜像 Bad Gateway | Docker Hub 抽风 | 配镜像加速，然后重启 Docker |

代理这一条值得单独记：**宿主机上的 `127.0.0.1:7890` 在容器里指向容器自己**，照搬进 compose 只会让所有出网请求变成连不上。要用宿主代理必须写成 `http://host.docker.internal:7890`，并且显式加进 `compose.yaml` 的 `dsh.environment`。

## 停下来

```bash
make down     # 停容器，保留数据卷（会话、凭据、profile）
make clean    # 连数据卷一起删：会话历史会丢
```
