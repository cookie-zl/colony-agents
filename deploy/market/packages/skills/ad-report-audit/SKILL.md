# 广告报表口径核对

报表数字不可信时，**先摆证据再下结论**。这个技能的唯一目的是让「这个数对不对」可以被别人验证。

## 工作顺序

1. **取原始行**。在聚合之前，先保留至少 3 条原始记录（不做任何字段改名、单位换算、空值填充）。
2. **并排展示**。左右两列：左列是接口返回的原始字段（含字段名），右列是解析后的值。
   任何被丢弃的字段单独列出来说明为什么丢。
3. **标注口径**。每个指标至少确认四件事：

   | 维度 | 要确认的内容 |
   | --- | --- |
   | 时间归属 | 按展示时间、点击时间还是转化时间归因 |
   | 时区 | 报表时区与业务时区是否一致（跨平台最常见的一天误差来源） |
   | 币种 | 是否已换算、用的哪一天的汇率 |
   | 归因窗口 | 点击后 1 天 / 7 天，view-through 是否计入 |

4. **给差异，不给评价**。写成「A 平台 CTR 1.8%，B 平台 2.4%，差异来自分母：A 用展示数，B 用可见展示数」，
   而不是「B 平台效果更好」。

## 禁止事项

- 不要为了让数字「看起来合理」而调整归因或补数。
- 不要在没看到原始行的情况下给出「数据正常」的结论。
- 不要把缺失值当 0 参与均值计算。

## 输出模板

```
## 原始数据（前 3 行，未解析）
<原样贴出>

## 解析后
| 指标 | 原始字段 | 解析值 | 说明 |

## 口径差异
| 维度 | A | B | 影响 |

## 结论
（只写数据能支持的结论；支撑不足时写「无法判断，缺 X」）
```
